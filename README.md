# دار العطر — متجر عطور تعليمي

متجر إلكتروني بسيط: صفحة عرض منتجات + سلة + إرسال طلب لخادم يحفظه.
مبني بـ Node.js فقط، بدون أي مكتبة خارجية (لا حاجة لـ npm install).

## التشغيل محليًا
```
node server.js
```
ثم افتح: http://localhost:3000

## متغيرات البيئة
| المتغير | الوصف | الافتراضي |
|---|---|---|
| PORT | المنفذ الذي يستمع عليه الخادم | 3000 |
| ADMIN_CODE | رمز الدخول لعرض الطلبات في /api/admin/orders | admin123 |

**مهم:** غيّر ADMIN_CODE قبل النشر، وضعه في Environment Variables على المنصة، لا في الكود.

## عرض الطلبات (كمشرف)
افتح:
```
https://your-app.onrender.com/api/admin/orders?code=YOUR_ADMIN_CODE
```

## النشر على Render
1. ارفع هذا المجلد إلى مستودع GitHub **خاص (Private)**.
2. في Render: New → Web Service → اختر المستودع.
3. Build Command: اتركه فارغًا (لا توجد مكتبات لتثبيتها).
4. Start Command: `node server.js`
5. أضف متغير البيئة `ADMIN_CODE` برمز من اختيارك.
6. اضغط Deploy.

## ملاحظة عن حفظ الطلبات
الطلبات تُحفظ في `data/orders.json` على القرص. الخطة المجانية في Render
لا تحتفظ بالقرص بعد إعادة التشغيل، فالطلبات ستُفقد. للاستخدام الحقيقي
أضف قرصًا دائمًا (Persistent Disk) أو انقل التخزين لقاعدة بيانات.
